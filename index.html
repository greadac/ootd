사용 방법
오늘의코디를 200% 활용하는 방법
1

기온을 설정해요

「오늘의 코디」 화면에서 슬라이더로 기온을 맞춰주세요. -5°C ~ 35°C, 8개 구간에 따라 코디 세트가 자동으로 바뀝니다.

2

코디를 확인해요

각 구간마다 3가지 조합이 준비되어 있어요. 「다른 코디 보기」로 같은 기온대의 다른 조합을 볼 수 있어요.

3

옷 사진을 등록해요

「옷 등록」에서 옷 사진을 업로드할 수 있어요. 사진은 브라우저(localStorage)에 저장되며 서버로 전송되지 않아요. 옷 목록과 맞춤 추천에서 사진으로 표시됩니다.

4

AI로 케어라벨을 분석해요

「AI로 케어라벨 읽기」를 누르고 Anthropic API 키와 케어라벨 사진을 올리면 세탁 방법을 자동으로 분석해 메모에 넣어줘요. API 키는 console.anthropic.com에서 무료로 발급받을 수 있어요.

5

맞춤 추천을 받아요

「맞춤 추천」에서 내 옷장 기반으로 기온에 맞는 코디를 추천받아요. 사진이 등록된 옷은 사진으로 표시됩니다.

6

데이터를 백업해요

「백업 / 불러오기」에서 옷장 데이터를 JSON 파일로 저장할 수 있어요. 기기가 바뀌어도 파일만 있으면 바로 복원할 수 있어요.
